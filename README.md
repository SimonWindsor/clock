# Clock App 🕒

A simple digital clock built with HTML, CSS, and JavaScript. The clock updates in real time and displays the current hours, minutes, and seconds using JavaScript's `Date()` object.

*[Click to see it live](https://simonwindsor.github.io/clock)*

## Features
- Real-time digital clock
- Clean and minimal UI
- Beginner-friendly JavaScript implementation

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Open `index.html` in any modern browser.
